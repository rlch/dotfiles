# Decisions (ADRs)

Architecture Decision Records — one decision per file, append-only. Copy
[ADR-000](/docs/decisions/adr-000-record-architecture-decisions) as the template
for new records. Number them `adr-NNN-<slug>.md`.

When a decision's machine-checkable parts solidify, promote them to a
`Requirement: SHALL …` in `openspec/specs/<capability>/` and cite this ADR.
