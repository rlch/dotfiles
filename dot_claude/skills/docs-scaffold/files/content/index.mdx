# Architecture docs

The high-level view of this system — how the parts fit together, why they're
shaped that way, and how to operate them.

- **[Architecture](/docs/architecture)** — current state, target shape, the
  diagrams of how components interact.
- **[Decisions](/docs/decisions)** — ADRs: settled architectural choices.
- **[Glossary](/docs/glossary)** — shared terms.
- **[Runbooks](/docs/runbooks)** — operator playbooks.
- **[Conventions](/docs/CONVENTIONS)** — how this vault is organised.

Normative `SHALL` requirements live in `openspec/specs/`; this vault is the
prose and justification around them.
